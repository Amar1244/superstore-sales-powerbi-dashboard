# Superstore Sales Analysis Dashboard | Power BI

A Power BI dashboard that analyses retail sales and profit for a Superstore business, so managers can see what sells, where, and to whom.

## About the data

`SuperStore_Sales_Dataset.csv` holds 5,901 order lines from 3,003 orders and 773 customers, placed between January 2019 and December 2020 across the United States. Each row has order and ship dates, ship mode, customer segment, region, state and city, product category and sub-category, sales, quantity, profit, returns and payment mode.

## What the dashboard covers

- **Sales and profit:** totals and trends over time, with the dataset adding up to about 1.57M in sales and 175K in profit.
- **Product performance:** Furniture, Office Supplies and Technology, down to sub-category and product.
- **Regional performance:** East, West, Central and South, down to state and city.
- **Customers:** Consumer, Corporate and Home Office segments.
- **Operations:** ship mode, payment mode (COD, Cards, Online) and returned orders.

A recorded walkthrough of the dashboard is included as an `.mp4` file.

## Tech stack

Power BI Desktop, DAX, data cleaning and modelling, CSV data source.
